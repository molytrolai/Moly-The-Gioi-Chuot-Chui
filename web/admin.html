Trạng Thái Hạ Tầng & Triển Khai Cloud

• Cơ sở dữ liệu: Neon PostgreSQL Cloud (hoặc dự phòng accounts.json độc lập)

• Máy chủ Ứng dụng: Render Web Service (Chạy container Docker tối ưu hóa)

• CDN & Tên miền: Cloudflare (Bật WebSockets, TLS Full/Strict, Cache tĩnh)

• Hỗ trợ Tri-Play: Web Browser Ruffle, Android APK (13MB), Desktop Portable (150MB)
