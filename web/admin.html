Phát Sóng Thông Báo Toàn Cõi Moly

Gửi thông báo chạy chữ trên màn hình tất cả người chơi đang kết nối trong game.

Trạng Thái Hạ Tầng & Triển Khai Cloud

• Cơ sở dữ liệu: Neon PostgreSQL Cloud (hoặc dự phòng accounts.json độc lập)

• Máy chủ Ứng dụng: Render Web Service (Chạy container Docker tối ưu hóa)

• CDN & Tên miền: Cloudflare (Bật WebSockets, TLS Full/Strict, Cache tĩnh)

• Hỗ trợ Tri-Play: Web Browser Ruffle, Android APK (13MB), Desktop Portable (150MB)

📦 Sao Lưu Dữ Liệu 1-Chạm (1-Click Database Backup)

Tải về ngay lập tức toàn bộ cơ sở dữ liệu hệ thống Moly (tài khoản cư dân, đơn nạp tiền, giftcode, cấu hình QR, lịch sử giao dịch) dưới dạng file nén ZIP để lưu trữ an toàn trên máy tính cá nhân phòng ngừa rủi ro.

📧 Cấu Hình Gửi Mã OTP Qua Gmail App (Mật Khẩu Ứng Dụng 16 Ký Tự)

Hệ thống tự động gửi email chứa mã OTP 6 số qua giao thức bảo mật SMTP SSL (cổng 465) của Google. Bạn cần bật Bảo Mật 2 Lớp trên tài khoản Google và tạo một Mật khẩu ứng dụng 16 ký tự tại trang myaccount.google.com/apppasswords.
