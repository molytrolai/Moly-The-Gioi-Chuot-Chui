❓ Hướng Dẫn Cài Đặt & Câu Hỏi Thường Gặp (FAQ)

📱 Cài đặt bản Android (APK - 13 MB) như thế nào?

1. Bấm nút "Tải Bản Android" để tải file APK về điện thoại.
2. Mở file và chọn "Cài đặt". Nếu điện thoại hiện cảnh báo nguồn lạ, chọn "Cho phép cài đặt từ nguồn này".
3. Mở ứng dụng, chạm màn hình để di chuyển và trải nghiệm mượt mà không cần Flash plugin!

💻 Chạy bản máy tính Windows (PC - 150 MB) có cần cài đặt không?

Bản máy tính là bản Portable độc lập hoàn toàn. Chỉ cần giải nén file .zip và bấm chạy trực tiếp file Moly The Gioi Chuot Chui.exe. Tỷ lệ hình ảnh chuẩn 12:7 sắc nét và không bao giờ bị lỗi viền đen.

🌐 Chơi trên Web Ruffle có lưu dữ liệu không?

Mọi dữ liệu nhân vật, trang phục, nhà cửa và thú cưng đều được đồng bộ tự động lên máy chủ đám mây. Bạn có thể đổi thiết bị thoải mái từ máy tính sang điện thoại mà không mất bất kỳ vật phẩm nào!
