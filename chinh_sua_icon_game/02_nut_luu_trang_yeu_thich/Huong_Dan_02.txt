Nút 'Lưu Trang Yêu Thích / Đánh Dấu' (收藏摩尔庄园 - hình rương báu).
Bao gồm 3 trạng thái: bình thường, rê chuột và bấm chuột.

CÁCH SỬA:
1. Mở file .png bằng Paint, Photoshop, Canva, v.v.
2. Chỉnh sửa chữ hoặc hình theo ý bạn (giữ nguyên kích thước và nền trong suốt PNG).
3. Lưu đè lên file ảnh.
4. Ra thư mục gốc chạy file 'Cap-Nhat-Icon-Sau-Khi-Sua.bat' là game sẽ cập nhật ngay lập tức!
